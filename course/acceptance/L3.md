# L3 连续经营剧本：从 08 演练到契约

`scenarios/L3-SIM-01.json` 由 [tools/build_l3.py](tools/build_l3.py) 生成，来源是 `app/simulation/run.py` 的 `run_day()`（`journey/08-business-simulation.md` 中 7 日、12 人、105 事件、831 项核对的那次演练）。

```bash
python3 course/acceptance/tools/build_l3.py      # 重新生成；计划偏离 08 基线时会拒绝写出
python3 course/acceptance/accept.py --only L3-SIM-01 ...
```

## 与 08 原版的差异

| 项 | 08 原版 | L3 契约版 |
|---|---|---|
| 日期 | 运行当天往前 7 天（基线为 2026-10-21 至 10-27） | 固定为 2026-07-15（周三）至 07-21（周二），星期分布与基线相同 |
| 驱动 | 讲师 CC4 的 HTTP API | 契约动作，任何实现都能跑 |
| 规模 | 105 事件 / 831 项核对 | 142 个契约动作 / 149 项检查（被排除的事件见下表；原版每个事件内含多项回读，因此检查项更多） |
| 资金基线 | 77 单、销售 ¥7,623、流入 ¥8,323、流出 ¥528.50 | **完全一致**，导出器在生成前逐项校验 |

## 期望值推导

7 月共 23 个工作日；演练日期中 07-15、16、17、20、21 是工作日，18、19 是周末。

**资深销售（A 级）**：每天都有订单。底薪 = floor(2200 × 有效出勤 ÷ 23)，只统计工作日。D2 和 D6 记半天，考勤记录优先于"有订单即出勤"。

| 截至 | 有效出勤 | 底薪 | 累计提成 | 合计 |
|---|---|---|---|---|
| D0 07-15 | 1 | 95 | 30 | 125 |
| D1 07-16 | 2 | 191 | 100 | 291 |
| D2 07-17 | 2.5 | 239 | 260 | 499 |
| D3 07-18 周六 | 2.5 | 239 | 290 | 529 |
| D4 07-19 周日 | 2.5 | 239 | 360 | 599 |
| D5 07-20 | 3.5 | 334 | 520 | 854 |
| D6 07-21 | 4 | 382 | 550 | 932 |

**成长销售**：当日订单在自录审核后为 D0–D2 每天 2 单（提成 20），D3–D6 每天 6 单（提成 100）。工资按月末等级计算：

| 截至 | 月末等级 | 固定部分 | 累计提成 | 合计 |
|---|---|---|---|---|
| D0–D2 | C | 前 3 个工作日 × 30 = 90 | 20 / 40 / 60 | 110 / 130 / 150 |
| D3–D5 | B（07-18 生效） | 07-18 起的工作日远多于 6 天，取满额 6 × 88 = 528 | 160 / 260 / 360 | 688 / 788 / 888 |
| D6 | A（07-21 生效） | floor(2200 × 5 ÷ 23) = 478（有订单的 5 个工作日） | 460 | 938 |

**当日新销售（C 级）**：90 + 1 单提成 10 = 100。D1、D5 的请假者不做工资断言，因为规则卡 R03 没有写明请假是否影响 C 级的 3 天额度。

**资金**：每日流入 = 当日订单数 × 99 + 回款 100；每日流出 = 65.50，D0 另加已发工资 70。七日累计流入 8,323，流出 528.50。

## L3 单独能抓到什么

用 `examples/toy_system.py` 的 8 种错误变体分别只跑 L3：

| 变体 | L3 结果 | 说明 |
|---|---|---|
| 提成线性 | 失败（D0 结算员工 5 单） | |
| 待审订单计入 | 失败（D0 自录第 3 笔） | |
| 允许超收 | 失败（D0 首款后） | |
| 重复发放重复计流出 | 失败（D0 重复发放） | |
| C/B 额度每月重置、历史月份按当前等级 | 通过 | 需要跨月才会暴露，08 演练只覆盖一个月，由 L1 抓 |
| 请假日被录单覆盖 | 通过 | 08 中请假者是 C 级，C 级额度不看出勤，由 L1-R07 抓 |

所以 L3 不能替代 L1/L2。它的作用是验证这些规则在连续经营中**叠加**以后仍然算得对。L1、L2、L3 合起来能抓到全部 8 种错误。
