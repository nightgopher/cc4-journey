## 最新重写决策

以技能的 Operate 模式执行。用户已将设计决策委托给本次实施，因此省略访谈与概念选择页；不把自动选择冒充用户选定。

设计候选从教育团队熟悉的内容体系推导，按关联度排序：校务行政指引、开班名册、校园导视、课程出版索引、学习小组通讯、招生资料夹、教务周计划。已运行本仓库 concept-seed，采用第七项，参考编号 `seed:8172aa0b72d239c7`。

“教务周计划”只贡献字体、颜色、密度和一处特征：概览的可操作周日期条。保留熟悉的业务导航、筛选、表单和表格，不把整个页面做成纸质课表。配色为海军蓝导航、清晰白色内容、蓝色操作色，待办与财务状态用独立的语义颜色；中文系统字体适合长期录入。

对技能给出的挑战方向按产品清晰度与教育团队关联度判断：园区地图的色块、字样构成网格、透明手册页、机票票夹、展会目录与光谱轨道均不替换工作台的控制与布局。取其可迁移的纪律：清楚的区域归属、稳定对齐、模块层级、URL 状态、紧凑且可读的信息密度、状态不能只靠颜色。没有安装装饰效果库。

### Direction contract（形式化既有决策）

以下五块在独立评审时从上述决策整理，补齐技能要求的结构；不构成新的视觉方向或用户确认记录。

- **THESIS**：同一教育电销工作台把客户跟进、业绩审核、出勤与薪资核对连接起来；以可核对的业务记录完成日常任务。
- **OWN-WORLD**：教务周计划只贡献海军蓝、蓝白区域、系统中文字体和紧凑密度；可操作日期条为唯一特征。使用者全天在办公屏幕上处理业务，熟悉的控件优先。
- **STORY**：选择业务日期 → 核对订单、销售额、出勤和待审数量 → 查看七日变化与产品构成 → 进入对应业务列表处理。每个列表保持标题、筛选、表格与操作的稳定顺序。
- **FIRST VIEWPORT**：桌面展示导航、当前页面与业务日期、七日日期条、四项摘要，并进入销售趋势与产品构成；手机先显示日期与摘要，后续内容纵向排列。切换日期条不移动整周，日期输入改变周区间。
- **FORM**：React + TypeScript 原生语义控件、受保护的短任务 dialog、可滚动的密集业务表格、自绘同一笔画 SVG 图标、中文状态；色彩和字重承担层级。加载/错误/空结果/未保存退出/键盘焦点/窄屏状态均为交付范围。

Operate 质量标准：任务可发现、数据来自 API、操作后状态明确、数字可比较、长表单按钮可达、键盘与手机具备同等功能。未生成概念图，也不存在用户批准的 comp。

## 两遍设计法：计划与复核

产品是每日使用的电销运营工作台。采用海军蓝导航与白色内容区，数据表格承担核对任务，操作与筛选保持稳定位置。主令牌以 `app/web/src/styles.css` 和 `app/web/src/lib/tokens.ts` 为准；最终系统记录见根目录 DESIGN.md。

经营概览通过可操作的七日日期条切换当天汇总，周区间保持稳定；输入新日期才切换整周。桌面同时核对趋势与产品构成，窄屏按业务顺序纵向排列。

常规宽度：

```text
分组导航 | 页面标题                          主要操作
         | 搜索 / 状态 / 日期 / 团队筛选
         | 业务表格                          行操作
         | 结果数                             分页
```

窄屏：

```text
菜单 / 当前页面
标题 / 主要操作
可换行的筛选
横向滚动的业务表格
结果数 / 分页
```

短任务采用原生 dialog，具有焦点管理、Escape、取消、原生表单校验；长流程留在业务页。列表加载、失败重试、空结果、保存中、保存成功与删除确认均有明确状态。

## ui-library-selector 选型

| 表面 | 用户、边界与任务 | 权重（合计 100%） |
|---|---|---|
| 登录 | 未登录用户进入工作台，独立认证边界 | 可靠性30、可访问性30、任务效率20、维护性15、视觉辨识5 |
| 业务工作台 | 登录用户按角色处理列表与表单 | 可靠性30、可访问性25、任务效率25、维护性15、视觉辨识5 |
| 经营概览 | 经理与管理人员核对日期范围内数据 | 任务效率30、可靠性25、可访问性20、性能15、维护性10 |

| 表面 | 行为基础 | 视觉效果来源 | 动画编排 |
|---|---|---|---|
| 登录 | 现有 React 组件与原生 form/input | 无：任务是身份验证 | CSS 操作状态，无入场动画 |
| 业务工作台 | 改进现有 kit；原生 dialog/select/table | 无：避免影响高频录入与核对 | CSS 短暂状态变化，尊重 reduced-motion |
| 经营概览 | 现有组件、语义化数据表与 SVG 真实数据图 | 无装饰性效果 | 无：数据更新直接可见 |

项目已检查 package.json、锁文件、kit.tsx、tokens.ts 和 styles.css，依赖为 React/React DOM。现有表格按页载入，暂不涉及虚拟化网格、拖放、复杂日期控件。Ant Design/MUI/Mantine 适合更复杂的后台，但当前会增加一套与既有组件重复的样式和接口；保留本地组件并修复焦点、响应式和刷新行为。本次不安装组件库，registry search/view/dry-run 不适用；未声称测得新库的性能差异。
