# 个人 MCP Token 发布与验收

2026-10-27，应用版本 `c81bc0a96b528f5c2dc36d063f7ebe7f0459ea28` 已通过 [GitHub Actions 发布](https://github.com/nightgopher/cc4-journey/actions/runs/40494260638)。公网前端版本、API 健康检查和服务器当前 release 均对应此版本。

## 使用入口

- [个人中心 → Agent 接入](https://150.5.143.32/cc4/?view=profile)：生成配置、重置、断开。
- 远程 MCP：`https://150.5.143.32/mcp`，Streamable HTTP，Bearer Header。
- 每个账号仅一把有效 Token，无自动过期；明文只在生成时展示，数据库仅保存哈希。
- 默认仅查询。允许业务写入仍需当前账号的角色、职位模块和目标员工/团队权限；普通员工不能借代录工具绕过自录审批。
- 用户退出网页或网页登录态到期不影响长期 Token；撤销、重置、停用账号或员工离职影响下一次请求。已有会话不会缓存旧权限。

工具与数据范围、接口和客户端配置见 [MCP 接入说明](../app/MCP.md) 与 [授权设计](11-mcp-demo-authorization.md)。这是支持自定义 Header 的演示接入，未增加 OAuth 授权服务器。
